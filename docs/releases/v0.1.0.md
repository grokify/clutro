# Release Notes v0.1.0

**Release Date:** October 14, 2026

## Overview

This is the initial release of CLUTRO, a pure-Go clustering toolkit for
sparse and dense data built around the optimization-criterion approach of
CLUTO: repeated bisection, spherical k-means, a pluggable criterion
function, cluster explanation, and deterministic results — with no
dependencies outside the Go standard library, for the library and the CLI
alike.

The release covers Phases 1–4 of the [roadmap](../specs/ROADMAP.md). The
remaining CLUTO criteria (I1, E1, G1, G1′, H1, H2), per-level refinement and
agglomerative clustering follow in v0.2.

## Installation

```bash
go get github.com/grokify/clutro@v0.1.0
go install github.com/grokify/clutro/cmd/clutro@v0.1.0
```

## Features

### Matrices and similarity

`matrix.CSR` (sparse, float32 values, uint32 columns) and `matrix.Dense`
behind one `Rows` interface; L2 row normalization and IDF column weighting
(`matrix.Preprocess`, CLUTO's `-rowmodel`/`-colmodel`); merge-join dot
products; cluster composite vectors with O(nnz) incremental add/remove.
`metric.Cosine` and `metric.Euclidean`.

### Criterion-driven clustering

`clutro.Fit` with `RepeatedBisection` (CLUTO `rb`; `rbr` with
`WithRefinement`), `Direct` and `KMeans` (spherical under cosine), all
optimizing the I2 criterion with greedy k-means++ seeding and multiple
seeded trials. Repeated bisection returns its tree, so `CutMaxSize` and
`CutK` re-partition without re-clustering. Defaults match CLUTO's.

### Explanation

`Describe` (descriptive features), `Discriminate` (what sets a cluster
apart), `Representatives` (most central rows) and `Summaries` (size, ISim,
ESim) — CLUTO's `-showfeatures` and `-showsummaries` as library calls, in
words when column labels are given.

### Evaluation

External: adjusted Rand index, NMI, purity, entropy. Internal: silhouette
(sampled above 10,000 rows), Davies–Bouldin, Calinski–Harabasz. Reference
values cross-checked against scikit-learn.

### Determinism

Same input, options, seed and version give identical labels regardless of
`GOMAXPROCS`. Random choices come from named seeded sub-streams, parallel
reductions are order-independent, and the optimized paths are tested
against slow reference implementations; a CI job runs the suite under
several `GOMAXPROCS` values.

### CLUTO compatibility

Readers and writers for CLUTO's matrix, label and clustering files; the
`clutro vcluster` command with CLUTO's flag names and defaults; and a
`golden` harness that re-clusters CLUTO corpora and compares. On 103 real
text corpora, CLUTRO's partitions score 1.0007× (`rb`) to 1.033× (`rbr`)
of CLUTO's on the criterion CLUTO optimized; eight numeric-only corpora are
published as fixtures with an asserted agreement band.

### Interoperability

`examples/hdbscan` (a separate module) feeds CLUTRO matrices to
`github.com/kinn-gg/hdbscan` for density-based clustering, which CLUTRO
deliberately does not reimplement.

## Known Limitations

- Only the I2 criterion is implemented; `-crfun` accepts nothing else yet.
- `rbr` refines the final partition, not after every bisection as CLUTO
  does (a v0.2 option).
- No agglomerative clustering, graph (`scluster`) input or
  feature-subspace cluster selection.
- Per-cluster features are a library call, not yet a CLI command.
- Row and column labels in `.rlabel`/`.clabel` files are read but the CLI
  does not yet print features by name.
